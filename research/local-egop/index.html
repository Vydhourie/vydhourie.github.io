Local EGOP for Continuous Index Learning

Alex Kokot, Anand Hemmady, Vydhourie Thiyageswaran, Marina Meila

Preprint · arXiv:2601.07061

Overview

A high-dimensional function may vary along only a few directions near any given input, while those directions change across inputs. Local EGOP learning adapts a kernel metric using expected gradient outer products to identify this local structure. The analysis establishes learning rates governed by intrinsic dimension under a supervised noisy-manifold hypothesis.
