An Optimization Framework for Focal Node Selection in Interference Detection

Vydhourie Thiyageswaran, Maryam Fazel

Working paper

Overview

Conditional randomization tests hold focal treatment assignments fixed while rerandomizing auxiliary assignments. We study how to choose focal units to improve power, using characterizations that account for exposure information and dependence. The framework connects optimization-based selection with existing heuristics and highlights the trade-off between including more focal units and retaining useful exposure variation.
